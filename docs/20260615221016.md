## Context

The two-adoption-axes decision (20260615100011) established `level` (incidental → trial → preference → requirement) and `state` (actual | target) as independent fields. However, gap docs created during the first ingest pass were tagged `level: incidental, state: actual` — framing deferred design choices as accidental current facts. This conflation hides intent and makes deferrals unsearchable.

A deferred decision is one the team has made (we WILL do X) but has not yet implemented. It is not accidental; it is deliberate. Modeling it as `incidental/actual` loses this signal entirely.

## Decision

A decision that the team intends but has not yet realized is recorded as `level: preference, state: target`. This combination means: "we have made a deliberate choice (preference, not incidental) but it is not yet reflected in the system (target, not actual)."

A decision that documents current realized behavior is recorded as `level: preference, state: actual`.

`level: incidental` is reserved for patterns that emerged without deliberate choice — things that are true but were never actively decided.

## Consequences

- Deferrals become first-class, searchable items: any doc with `state: target` is a known gap between intention and reality.
- The `living over stale` principle (20260615100001) is served: the corpus accurately represents both what IS and what is INTENDED, without conflating them.
- Gap docs (decisions extracted from brainstorm/ingest material) should be evaluated at creation time: is this a realized behavior (preference/actual) or a deferred intention (preference/target)?
- `state: target` docs that remain unrealized over time become actionable debt items, visible to the garden skill.

## Correction

The `state` field no longer exists. The schema migration (2026-06-17) folded `state: actual|target` into the `status` enum. A deferred decision is now recorded as `status: target` (no separate `state` field). The distinction between realized and intended is captured entirely by the four-value `status` enum — see [[20260617212538]].
