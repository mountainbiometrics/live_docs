## Statement

Maintaining docs is more painful than maintaining code; without tooling the system will not get used. Maximize automated checks; the system defines its own library of skills for maintaining, curating, and enriching its content.

## Rationale

Documentation systems that rely purely on human discipline fail over time. The burden must be shifted to tooling: automated cascade checks, ingest pipelines, gardening skills. A system that documents itself using skills defined in the same corpus creates a virtuous loop where the docs improve the tooling and the tooling maintains the docs.
