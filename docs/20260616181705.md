## Goal

Official live_docs must be **reviewable**. Unlike panelist *private* memory, official docs are canonical and shared — they are authoritative for everyone who reads them. Because changes to canonical knowledge carry weight, there must be a path by which those changes can be reviewed.

## Why

The official-vs-private distinction (see panel-sensor) is what makes review necessary here and not for private memory. A panelist's scratch memory answers only to that panelist; a wrong note costs one agent. An official doc that drifts or asserts something false misleads every reader confidently. A review path is the mechanism that lets canonical changes be contested and corrected, keeping the shared store trustworthy and maintainable.

## Scope note

This goal states *that* official docs must be reviewable. The shape of the review path — post-hoc vs gating, what reviewers read, how signoffs work — is decided in the dependent decisions, not here.
