## Context

Ids are opaque (Kiste/Zettelkasten) and titles are descriptive but long, so neither is a friendly handle for humans or agents referencing docs in commands and skill steps.

## Decision

Every doc carries a short, unique, kebab-case `slug` in addition to `title`. Resolution accepts id, slug, or title substring — whichever the caller finds most natural.

## Consequences

- Humans and agents reference docs by slug in `ld` commands and prose.
- Display labels stay compact (slug is scannable; title is readable in full context).
- Titles stay descriptive without needing to be terse.
