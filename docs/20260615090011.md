## Overview

live_docs is a self-documenting atomic-documentation system. Every piece of knowledge about the system lives in a flat `docs/` store as a markdown file with typed, structured frontmatter. This repo (codename "sinai") is simultaneously the definition and the first instance of live_docs: the system-spec docs are tagged `scope: [live_docs]`, while MTN-specific docs are tagged `scope: [sinai]` or a more specific domain.

Filenames are opaque timestamp IDs (Zettelkasten/"Kiste" style). The `title` field in frontmatter is the only place a human-readable name lives. To navigate, start here and follow `depends_on` edges or consult the type-specific index docs listed below.

To create a new doc: `python scripts/new_doc.py --type <type> --title "<title>" [options]`
