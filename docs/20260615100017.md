## Context

live_docs is being built inside the sinai repo, which is MTN's specific project. System-level docs (principles, decisions about the doc system itself) need to be separable from MTN-specific domain docs.

## Decision

System-specification docs are tagged `scope: [live_docs]` so they can be extracted into a standalone repo later. MTN-specific docs accumulate alongside without this tag.

## Consequences

The system stays portable (P1): live_docs can be adopted by other teams or repos by extracting all `scope: live_docs` tagged docs. MTN-specific knowledge does not pollute the generic system definition. The tag discipline must be maintained; a gardening skill can verify that system-spec docs carry the tag and MTN-specific docs do not.
