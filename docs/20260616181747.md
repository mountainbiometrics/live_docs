## Decision

Signoffs are tracked like **git authorship: free-text signatures, no registry.** A review summary accumulates signature entries `{who, at}`, where `who` is whatever name the signer used.

- **Optional** — an unsigned summary is still blessed (review is post-hoc; see review-is-post-hoc); it simply has no signatures yet.
- **Multi-person / multi-role** — anyone can sign, and several people or roles can sign the same summary. A meticulous reviewer can sign things others already signed. A reviewer is effectively a role, so a domain panelist signing a summary in their domain is the same primitive (see panel-sensor).
- **No registry, no identity reconciliation** — the system tracks no canonical set of people. If one person signs as `swecker`, `Samuel`, and `Super Steve`, the summary simply shows three signatures; that is the signer's own concern. The only identity the system needs is the **current actor**, used solely to filter "summaries not yet signed by me" (`ldoc review list --unsigned-by <me>`). Future porcelain can help normalize inconsistent signatures if it ever matters.
