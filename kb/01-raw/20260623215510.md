Viewer improvements (session requests, implemented in scripts/viewer/template.html):

1. Sidebar nesting: show visual hierarchy so nested vs sibling is discernible without toggling sections — depth indent (minimal, ~6px per level via nested containers), vertical guide lines, disclosure carets, child-count badges on signposts.

2. Doc ordering: replace implicit sort (subtree size at roots, signposts-before-leaves in lists) with type-then-alphabetical-by-label everywhere the viewer lists docs without an established sort pattern. Type order (high-level → concrete): use-case > principle > requirement > constraint > component > decision > guide > reference; unknown types after reference, alpha by type name. Reviews keep newest-first; catalog column clicks override default; dashboard signposts keep subtree-size ranking; hot docs keep history-count ranking.

3. Reader sidebar state: preserve collapse/expand and scroll position when navigating between reader pages — build tree shell once, update content pane only; on link navigation open belongs_to ancestor path without resetting other sections; highlight active signpost summaries too.

4. Tree toolbar: Expand all / Collapse all buttons. Default on load: top-level signposts (and Ungrouped) expanded, nested folders collapsed. Expand all opens every details; Collapse all closes every details including top-level.
