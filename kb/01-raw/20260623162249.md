Add provenance metadata to the live_docs capture→ingest pipeline so material from heterogeneous sources (Notion docs, files from different codebases, PDFs, scanned pages) can be ingested with enough origin/age context for downstream staleness reasoning.

1. Three new OPTIONAL provenance fields, captured as early as gate 0 (ldoc inbox add) and carried losslessly forward through gate 1 (ldoc promote) onto the raw clipping:
   - origin — the corpus/system the material came from (e.g. notion, codebase:foo, codebase:bar). This is the namespace axis distinguishing not just medium (Notion vs. code) but instance (repo1 vs. repo2).
   - medium — the medium of the source (e.g. pdf, scan, notion-page, source-file, transcript).
   - authored_at — when the SOURCE material was written, allowed to be fuzzy (2024-03, circa 2023). CLI flag is --authored-at, stored as authored_at.

2. Three distinct timestamps with distinct meanings (core rationale): authored_at (when the source was written) vs. captured (when it was dropped into the inbox) vs. imported (when it was promoted to raw). Previously only imported survived to the raw tier — captured was silently dropped at promotion and there was nowhere to record authored_at at all. Mixing 2-year-old docs with 2-week-old docs requires authored_at.

3. Latent fix: the raw clipping status was inconsistently written as the non-enum value 'historical' (in ingest_raw.py and promote) vs. 'reference' (in kb.py); standardized to the valid enum value 'reference'.

4. Deferred follow-on work (planned/target, not done):
   - Stamp origin/medium/authored_at onto the normalized reference (graph) doc too, so extracted atomic docs can reach source-age via their provenance edge. Requires extending REFERENCE_EXTRA_FIELDS and ldoc new.
   - Add ingest-state to raw items (pending/ingested) plus a 'raw list --pending' view, to enable batch 'process the backlog over time.'
   - A shard-clipping pre-pass (gate 1.5) that splits oversized clippings along concept seams into child raw clippings before ingest, to fix large-doc ingest stalls.
