Configurable viewer build output path.

Design locked in conversation:
1. Key: [viewer] build_path in .live_docs.toml (file path for the HTML artifact). Default when omitted: build/viewer.html.
2. Resolve relative to STORE_ROOT. Absolute paths and escapes outside the store fail loud (do not silently reinterpret /tmp/x.html as STORE_ROOT/tmp/x.html).
3. Honored by both `ldoc viewer` and porcelain auto-rebuild. CLI `--out` still wins for one-shot builds and does not rewrite the config default.
4. [viewer] may carry this artifact path — it is a viewer concern, not box relocation. The older "presentation not paths" framing for [viewer] is over-separated; favicon was already a path.
5. Outside-store publish stays via symlink/copy; config does not write outside STORE_ROOT.
