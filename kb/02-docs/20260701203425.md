Actualize the formerly-virtual "episode" as a first-class Editing Session component in the Review Subsystem — the unit of editing work that one owner opens, stamps every change to, and closes to mint exactly one review summary — and gather the session decisions (explicit-id identity, session-stamped history) under it so the review subsystem stays cohesive. Rename the identity decision to be session-explicit and lift its "session is the episode made explicit" framing into the component doc; re-home the edge-based review classification under the Review Summary component. Additionally record the architectural decision that a session propagates ambiently through the shell via the LDOC_SESSION environment variable — so independent ldoc invocations, and subagents that inherit the environment, all attribute their changes to the same open session without threading a session id through command arguments — chosen over explicit per-command passing or a persisted state file. Plus the smaller durable facts that a session id is time-sortable yet collision-resistant, and that closing a session is what mints its review summary.
