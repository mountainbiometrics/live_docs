Two constraints govern how the live_docs system communicates with and is operated by LLM agents. First, the ldoc CLI is the only tool an agent should ever need — no raw shell commands (rm, grep, find, etc.) are acceptable workarounds, because portability across repos and environments requires a single clean interface. Second, policies and constraints intended for agents outside this repo must be baked into skills or the CLI itself; the internal KB and repo-specific files (README.md, AGENTS.md) are invisible to external agents and therefore cannot serve as the distribution channel for agent-facing contracts.
