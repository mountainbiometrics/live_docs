## Principle

When a single clipping is too large to ingest in one agent context, the correct response is to **divide the unit of work, not the phases of work**. Shrink the oversized clipping into smaller verbatim units, and ingest each unit *whole* — comprehending and synthesizing it in one pass. Never cut a single ingest into a separate plan-phase and apply-phase.

## Why phases cannot be split

Comprehension and synthesis are not separable phases for one conceptual unit; they are a single act. A plan/apply split fails both ways:

- If the plan is to be executed faithfully by a context-light applier, it must **serialize everything the writer needs** — every doc body, every edge, every provenance link. At that point the planner has already done the writing in all but name, and the applier is redundant.
- If instead the applier is given latitude to write well, it needs the **nuance only available during comprehension** — the surrounding argument, the framing, the cross-references. The plan necessarily dropped that nuance, so the applier re-comprehends from a lossy summary, reintroducing the exact quality loss the split was meant to avoid.

Either way the synthesis degrades. The unit, by contrast, can be made smaller without losing anything: a smaller verbatim unit is still comprehended and synthesized together, just over less material.

This is the founding rationale for shard-clipping (gate 1.5): it shrinks the unit, it does not split the phases.
