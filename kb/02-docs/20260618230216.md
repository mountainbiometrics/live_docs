The lifecycle and schema of a single doc: status/level axes, what is_living governs, deprecation discipline, field conventions, history semantics, and how the type taxonomy is defined.

The schema entry point is `[[20260617212538]]` (Status Enum Unified), where one lifecycle field replaces the old state/status pair. `[[20260617212550]]` (Is Living Derived Axis) builds on it: is_living is derived and governs which docs cascade-check is allowed to rewrite. `[[20260617212602]]` (Deprecation Requires Supersession) sets the retirement discipline — a superseded_by edge plus a Correction section, not a bare status flip. The level axis is covered by `[[20260615100014]]` (Provenance or Incidental), where a missing source implies level: incidental, and `[[20260615203858]]` (Relevance Axis Deferred), which defers a generalizedness axis and uses level as the current proxy. `[[20260615100013]]` (Reference Kind Field) keeps reference subtypes a kind field rather than new top-level types, and `[[20260617212613]]` (Omit Empty Lists) sets the convention that absent means empty.

The history field has its own two docs. `[[20260615185431]]` (History Is Changes) establishes that history records only genuine changes, not a creation entry — creation time lives in created:, so the list starts empty. This makes history length a meaningful signal: `[[20260615203928]]` (Hot File Signal) formalizes that — a doc with an unusually long history list (threshold: ~5 entries) is a first-class decomposition candidate for the garden skill. Many history entries across varied topics is the churn signal that points to an SRP violation.

Two decisions govern the type taxonomy. `[[20260615100015]]` (Self-Defining Types) makes the system self-describing: each doc type is defined by a doc of type: type living inside the corpus, participating in the same cascade machinery as all other docs. `[[20260619234959]]` (No Index Type) retired the index type: a doc is a navigational signpost by virtue of having descendants, not by declaring a special type. Any type can hold descendants and play the signpost role; the role is read off topology, not off a type value.
