The lifecycle and schema of a single doc: status/level axes, what is_living governs, deprecation discipline, and frontmatter field rules.

The schema entry point is `[[20260617212538]]` (Status Enum Unified), where one lifecycle field replaces the old state/status pair. `[[20260617212550]]` (Is Living Derived Axis) builds on it: is_living is derived and governs which docs cascade-check is allowed to rewrite. `[[20260617212602]]` (Deprecation Requires Supersession) sets the retirement discipline — a superseded_by edge plus a Correction section, not a status flip. The level axis is covered by `[[20260615100014]]` (Provenance or Incidental), where a missing source implies level: incidental, and `[[20260615203858]]` (Relevance Axis Deferred), which defers generalizedness and uses level as the current proxy. `[[20260615100013]]` (Reference Kind Field) keeps reference subtypes a kind field rather than new top-level types, and `[[20260617212613]]` (Omit Empty Lists) sets the frontmatter convention that absent means empty.
