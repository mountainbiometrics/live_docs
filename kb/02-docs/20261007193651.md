## Requirement

The exception in [[20260625222638]] for a parent that only groups its children is a doc type. Validate and the mutators read that type. They do not infer the exception from the parent having children.

A parent of any other type keeps that type. Children do not remove its why.

## Why

[[20261007193650]] A checker can apply the exception and leave it off every parent that also makes a claim. The exception itself is already the why-rule's ([[20260625222638]]).
