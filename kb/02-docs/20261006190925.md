## Use-case

A person lets an agent keep the code and the design docs in step, in both directions. From docs to code, the agent finds claims the implementation does not yet realize and builds toward them. From code to docs, it finds what was built without a doc and records it ([[20260618214238]]).

## What it needs from the store

Two improvements make this something the person is comfortable handing to an agent. Each doc says what the person did to make its claim exist — asked for it, chose it, or let it happen — so the agent knows which claims it may revise and which it must hold to. And each doc whose claim can be built says whether it has been, so the agent can tell a backlog item from a finished one without reading the code.
