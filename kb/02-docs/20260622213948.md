## Decision

Per-user porcelain preferences live in **`~/.config/live_docs/config.toml`**, using a **git-compatible `[user]` table**:

```toml
[user]
name = "Samuel Wecker"
email = "samuel@themtn.ai"
```

The **`ldoc config`** verb reads and writes these keys git-style (`ldoc config user.name`, `ldoc config user.email`, `ldoc config signer`, `ldoc config --list`). **`ldoc config` does not require a located store** — it only touches the home config file.

**Default review sign-off** uses git's author-line format: `Name <email>` when both are set, or whichever part is configured. `ldoc review sign <ref>` picks this up automatically; **`--as` overrides** when supplied.

The same home config file may also hold **store-path fallbacks** (`inbox`, `raw`, `docs`, `reviews`) used when no `.live_docs.toml` is found walking up from the CWD. User identity keys and store-path keys coexist; store discovery ignores the `[user]` table.

## Bootstrap

`install.sh` calls `ldoc config --bootstrap-from-git` after installing the CLI when `user.name` is unset. This copies from **`git config --global`** — the supported git porcelain — not by parsing `~/.gitconfig` directly.

## Rationale

Review sign-offs already follow git authorship semantics (see signoffs-multi-reviewer). Making the default identity git-shaped removes repetitive `--as` flags and matches what developers already configure once for commits.
