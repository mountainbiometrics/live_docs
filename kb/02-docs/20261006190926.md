## Goal

Agents working with the store make iterative changes to docs as the work calls for. A claim an earlier agent proposed, which the person let stand or committed along with other work, does not stop the next agent from changing it. The claims the person asked for or picked stay distinguishable from those, so iteration does not wear them away.

## Why

Coding agents have refused iterative changes on the grounds that the person "had ratified the shape" of a doc, when the person had only let an agent's proposal stand. Pushing harder and harder for "no implementation details" in docs was a response to that, and it went too far. A person who commits a doc has in a loose sense approved it, but that does not make the claim any less incidental ([[20260723223658]]).
