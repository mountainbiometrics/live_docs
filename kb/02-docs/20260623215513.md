The read-only HTML viewer's Reader mode is refined for daily hierarchy navigation: the sidebar shows nesting visually (minimal per-level indent, guide lines, carets, child counts), lists docs by type-then-label using a fixed high-to-low type order unless a surface has its own sort (reviews, catalog columns, dashboard entry-point ranking), preserves sidebar expand/collapse and scroll across doc navigation while revealing the active doc's ancestor path, and adds Expand all / Collapse all with a default of top-level signposts open and nested sections closed.
