## Overview

live_docs is a self-documenting atomic-documentation system. Every piece of knowledge lives in the flat `kb/02-docs/` store as a markdown file with typed, structured frontmatter. This repo (codename "sinai") is simultaneously the definition and the first instance of live_docs: system-spec docs are tagged `scope: [live_docs]`, while MTN-specific docs are tagged `scope: [sinai]` or a more specific domain.

Filenames are opaque timestamp IDs; the human-readable name lives only in the `title` frontmatter field. Navigate with `ldoc find` / `ldoc ls`, or by following `requires` / `belongs_to` edges from any doc.

To create a new doc: `ldoc new --type <type> --title "<title>" [options]`

## Status: stub

This root index does not yet do anything load-bearing. Per the index/MOC design ([[20260615204138]] — Index Summaries, currently `target`), it is intended to become the top-level index of the system's highest-level MOCs — an *agentic* concept where one skill curates a grouping and another synthesizes an aggregated summary of it. That concept is not yet implemented.

An earlier hand-written "Type Catalog" section was removed: the per-type definition docs it referenced were deleted as non-weight-bearing orphans. The 11-value type taxonomy lives in `scripts/livedocs/model.py`, not as docs.
