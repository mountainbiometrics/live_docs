## Decision

When a review is minted from a session, it carries an **`integration`** frontmatter snapshot:

- **`new_to_new`** — forward edges among the session's new non-reference docs
- **`new_to_existing`** — forward edges from those new docs to living|target non-reference docs
- **`edges_added_to_existing`** — sum of WAL `edges_added` counts on non-new docs from `link`/`unlink`

Provenance edges and raw/reference targets are excluded. `type: reference` additions are demoted to `## Reference files` and excluded from the new-set. The snapshot is **point-in-time at mint** — not recomputed later from the live graph, and not backfilled onto legacy reviews.

## Why

The useful question is not vanity edge totals. It is: **did this session create an island of new docs, or did those docs (and edge work on existing docs) tie into the store?** Collapsed review cards surface these counts alongside new/revised/minor so a reviewer can judge integration before expanding the summary.
