## Statement

Capture information in a structure that is easily searched and navigated, not absorbed all at once. Hierarchy and index docs serve as signposts; detail is available on demand.

## Rationale

Both humans and LLMs have finite working context. A system that front-loads every detail on every read fails both audiences. The right structure lets a reader (or agent) locate the relevant doc and descend for specifics without first processing everything else. Searchability and selective depth are first-class design goals.
