## Context

The existing schema had only two edge types: depends_on (structural dependency) and references (provenance). As the graph grew, the need for cluster edges (non-cascading kinship) and proper structural hierarchy became clear. The design session iterated over a behavioral matrix to derive the minimal closed vocabulary.

## Decision

Four active edge types:

| Type | Direction | Cascade | Removal jeopardy | Structural? | Acyclic | Outside graph? |
|---|---|---|---|---|---|---|
| **belongs_to** | directed | both ways | yes — orphan | YES | yes | no |
| **requires** | directed | reverse strong | yes — slate removal | no | yes | no |
| **relates** | symmetric | none | none | no | n/a | no |
| **provenance** | directed | none | none | no | yes | YES |

**belongs_to** — a doc declares membership in a parent; removing the parent orphans this doc. Name chosen over 'part_of' because 'part_of' implies compositional (not a real axis); 'belongs_to' more sharply carries the orphan implication.

**requires** — a doc logically depends on another; removal of the required doc slates this doc for re-evaluation or removal. Cascade runs on the requiring doc when the required doc changes.

**relates** — symmetric, non-cascading cluster marker. Removal of one doc does not orphan the other. garden may prune stale relates edges.

**provenance** — records ingest lineage ('A was derived from B'). Immutable fact. validate enforces that all ingest-reference extractions carry this edge. Can target docs outside the graph (raw/, external URLs). garden must never prune provenance edges.

A fifth edge, **superseded_by**, points from a doc at its replacement: required on a deprecated doc ([[20260617212602]]) and allowed on a living doc whose planned successor coexists with it ([[20261006190947]]).

## Consequences

- The existing depends_on field is subsumed: depends_on covered structural dependency. Re-typing existing edges to belongs_to/requires happens opportunistically via garden, not a big-bang migration.
- The existing references field is renamed to provenance — see companion decision.
- Edge-typing parameterizes cascade-check, reindex, validate, and garden simultaneously (each reads the type to determine behavior).
