## Decision

The root of the store is **"The live_docs system" component** — the top of the `belongs_to` hierarchy. It should be a **synthesized map over the highest-level structural subsystems**, an agentic editorial map, **not a hand-written catalog**. It earns the signpost role **structurally** (it has descendants), not by any special `index` type — that type is retired. The earlier **per-type definition docs were deleted** as non-weight-bearing orphans.

## Rationale

A readme-style root catalog that lists docs which **define nothing** is dead weight. The **type taxonomy lives as enum values in code**, not as docs, so per-type definition docs added no authority. A signpost should be a **synthesized map** over real groupings — which follows directly from grouping-is-agentic: it is curated editorial judgment, never an auto-dump or a hand-maintained list. The root additionally **anchors the root scope**, inherited by the entire store.
