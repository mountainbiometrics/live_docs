## Decision

The root index doc is currently a **non-load-bearing stub**. If a root index is kept, it should become the **top-level index of the highest-level MOCs** — an agentic map over real groupings — not a hand-written catalog. The earlier **per-type definition docs were deleted** as non-weight-bearing orphans.

## Rationale

A readme-style root catalog that lists docs which **define nothing** is dead weight. The **type taxonomy lives as enum values in code**, not as docs, so per-type definition docs added no authority. An index should be a **synthesized MOC** over real groupings — which follows directly from grouping-is-agentic: an index is curated editorial judgment, never an auto-dump or a hand-maintained list.
