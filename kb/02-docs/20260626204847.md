Extend the ldoc porcelain with referential integrity around doc deletion and mechanical validate lints. ldoc rm blocks deletion when any inbound edge exists unless --force, which strips all inbound edges first. ldoc unlink accepts literal 14-digit dead ids for edge removal. validate adds warnings for staged-incomplete retirement (superseded_by without deprecated status), body [[id]] wikilinks missing from edge fields, and malformed wikilink syntax — body prose must use bare [[id]]. Dangling edge detection is unified across edges.py and validate for all blocking edge types. ldoc gc-edges is explicitly deferred.
