In live_docs, retirement has two distinct paths. Deletion (rm + ldoc reindex) is correct when a doc has no content not already captured elsewhere — duplicates, empty stubs, redundant variants after a merge. Deprecation (status: deprecated + superseded_by + Correction section) is correct when a doc recorded a genuine decision or belief that was later overturned, and preserving that history has value. The default is deletion: if removing the doc loses no information, delete it. Deprecation is not the default retirement path — it is specifically for cases where the historical record matters.
