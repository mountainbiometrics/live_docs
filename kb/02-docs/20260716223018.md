## What this is

The viewer exposes a dedicated **Lexicon** page — its own nav surface, structured similarly to Catalog but over term records, **not** a tab inside Catalog.

### Projection

- Resolve explicit soft term links (`[[Cascade]]`, `[[(Graph) Cascade]]`, `[[graph/cascade]]`) in rendered markdown
- Hover/tooltip definitions for linked terms
- Optional implicit auto-link of known terms as a formatting option (viewer config), without mandating body rewrites

### Usage stats

Cheap counts via search/backlinks: number of docs that reference a term; optional breakdowns by doc type / scope / domain. Not a heavy analytics system.
