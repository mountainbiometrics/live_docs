## Decision

The MCP endpoint ([[20260916171907]]) is packaged on its own and declares its own dependencies. The store's shared code and the `ldoc` CLI take on none of them, and `ldoc` behaves the same whether or not the endpoint is installed anywhere.

## Why

The endpoint is an optional part of the tool, the way git's own web server is optional. You don't add a dependency to a tool because an optional part of that tool has the dependency. So the price sits where the benefit is: a machine that only runs `ldoc` installs nothing for a surface it never runs, and installing the endpoint is a separate act from installing the tooling ([[20260703005021]]).
