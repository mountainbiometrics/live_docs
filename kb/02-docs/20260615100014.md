## Context

Docs vary in authority. Some derive from explicit decisions or external sources; others emerged organically without deliberate provenance. The system needs to distinguish these.

## Decision

Every doc should record its source or derivation. A doc with no recorded provenance is automatically treated as `level: incidental` — not a decided thing, just something that happened to be written down.

## Consequences

The distinction between decided and emergent knowledge becomes self-enforcing (P3): the metadata carries the signal without requiring a human to explicitly label everything "incidental." This creates a gentle incentive to record provenance — if you want a doc to carry weight, you have to say where it came from. Gardening passes can surface all `incidental` docs as candidates for elevation or deletion (P2, P6).
