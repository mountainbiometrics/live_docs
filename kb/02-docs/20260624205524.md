## Decision

`renderReviews` sorts reviews by id descending (newest first). Each card:

- **Collapsed head** — change-size line (new / revised / minor / reference-file counts from body sections), mint-time **integration** counts when the review carries them (`new→new`, `new→existing`, `edges on existing` — see `[[20260710235235]]`), created date, secondary id badge, and signoff badges (unsigned warning if none).
- **Expanded body** — session Summary text when present; change summary through `renderMarkdown`; copy button for `ldoc review sign <id>`.

Legacy reviews without an `integration` frontmatter block simply omit those edge counts — they are not recomputed from the live graph. The viewer never writes signoffs — the snippet is copy-paste only (`[[20260619204918]]`).
