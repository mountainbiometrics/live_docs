## Decision

`renderReviews` sorts reviews by id descending (newest first). Each card:

- **Collapsed head** — count of `touched` docs, created date, signoff badges (unsigned warning if none).
- **Expanded body** — change summary through `renderMarkdown`; copy button for `ldoc review sign <id>`.

The viewer never writes signoffs — the snippet is copy-paste only (`[[20260619204918]]`).
