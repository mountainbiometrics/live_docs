## Intent

Treat documentation like modules in code: every document should have high cohesion (everything in it relates to one concept), and documents should be loosely coupled (they reference each other via stable abstractions, not implementation details).

This is the modularity discipline behind live_docs atomicity — cohesion is the inward face (what belongs inside one doc), loose coupling is the outward face (how docs may depend on each other without baking in transient detail).
