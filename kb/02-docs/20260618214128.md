## Statement

When borrowing structure from prior art, adopt only its **incidental** conventions — directory naming, ordering, box layout, surface ergonomics. Wherever this system has already made an **explicit** decision, that decision wins over the borrowed convention.

## Rationale

Borrowing reduces novelty-cost and aids cross-system familiarity: a reader who knows the source recognises the shape. But deliberate choices encode reasons the other system does not share, so an explicit local decision must never be silently overwritten by an imported habit. The test is intent: if we chose something on purpose, it stands; if we merely inherited a shape with no local reason to differ, the borrowed convention is fine.

## Application

This principle decided the `kb/` numbered-box layout (borrowed from the schema-concept-learning-kb prior art) while leaving our own edge model and schema decisions untouched.
