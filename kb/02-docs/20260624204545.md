## Role

The **Catalog View** is one of the viewer's three navigation modes (`[[20260619204849]]`): the **facet** answer to "show me all docs matching these attributes." It renders every doc as a row in a filterable, groupable table computed client-side from the pure-data export.

Home (dashboard) and Reader (hierarchy sidebar + focus pane) are sibling integration surfaces under `[[20260619204727]]`; only Catalog has its own sub-component because facet/table UX accumulates enough localized decisions to warrant a grouping anchor.

## Scope of this component

Everything about **how the catalog table looks and behaves** — column set and order, in-row facet chips, filter dropdowns, group-by axes, and click-to-filter interaction. Cross-surface facet **display** (scope breadcrumbs and domain pills on tooltips, meta lines, lists) lives in `[[20260624202025]]`; schema-enum **label formatting** lives in `[[20260624204553]]`.
