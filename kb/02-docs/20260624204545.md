Top-level **Catalog** (`renderCatalog`). Implements the facet navigation mode from `[[20260619204849]]`.

A filterable table over every doc's frontmatter — scope and domain facets computed client-side along `belongs_to`. Table columns, click-to-filter chips, dropdowns, group-by, and sort: `[[20260624204552]]`. Default listings omit reference/archived docs per `[[20260717210152]]` (status filters can still surface them when the reader opts in).

Cross-surface facet display (breadcrumbs/pills outside the table) is governed by `[[20260624202025]]`; enum formatting by `[[20260624204553]]`.
