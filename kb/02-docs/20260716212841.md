## Restatement

The working session of 2026-07-16 removed the `keywords` frontmatter field entirely — a pure subtraction with no renamed replacement. The field was a flat, optional, ungoverned findability-synonym list that never earned its keep: rarely populated, never meaningfully governed, and overlapping what governed `domain` tags plus full-text search over title/label/body already cover.

Implementation removed CLI flags, find term-matching, canonical field order, validation, and change-type mapping for `keywords`, and stripped populated `keywords:` values from the few docs that had them.

A WISH.md "Integrated Lexicon" item remains an unbuilt future exploration of deliberate vocabulary — not a like-for-like replacement for the removed field, and neither decided-for nor blocked by this removal.
