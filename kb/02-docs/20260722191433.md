## Intent

The viewer HTML artifact path is store-configurable via `[viewer] build_path` in `.live_docs.toml`. Default remains `build/viewer.html`. Paths resolve relative to `STORE_ROOT`; absolute paths and escapes outside the store fail loud. Both `ldoc viewer` and auto-rebuild honor the config; CLI `--out` overrides for one-shot builds only. `[viewer]` may carry this artifact path as a viewer concern (not box relocation).
