## What it does

The sync skill walks the realizable docs ([[20261006190943]]) in a scope and, for each one:

- checks its anchors ([[20261006190944]]) against the implementation;
- sets `realization` and `realization_verified`;
- refreshes the doc's `## Implementation` section when it has one ([[20261006190945]]).

It reports two lists: living docs at `planned` that are still not built, and things in the implementation that no doc describes. The second list goes to reconcile-changes ([[20260618213505]]), which records already-real decisions in the store.

## Why

This is how an agent keeps code and docs in step in both directions ([[20261006190925]]): the docs say what is planned and whether it is built, and what was built without a doc gets one.
