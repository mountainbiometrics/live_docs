## What this component covers

**Store Interfaces** is the shared parent for every surface through which humans and agents read or operate the store. Its members are the ldoc porcelain/CLI ([[20260618230225]]), the optional HTML viewer ([[20260619204727]]), and the MCP endpoint that answers reads over a network ([[20260916171907]]). Future surfaces belong here too.

The store's logic lives once, in shared code ([[20260615185417]]). The CLI and the MCP endpoint are surfaces over it: each calls that code directly rather than calling — or running — the other. The viewer renders an export the CLI produces.

Cross-cutting rules that bind every surface live under this signpost: footnote-grade prominence of reference material ([[20260717210143]]), default demotion across orientation/search/validate ([[20260717210152]]), and porcelain immutability of reference snapshots ([[20260717210153]]). Implementation-specific decisions stay under the CLI, viewer, or endpoint child.
