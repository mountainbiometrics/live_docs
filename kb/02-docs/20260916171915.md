## The goal

Writers on several machines write into one shared store, not only read from it.

## What that asks for

Concurrent writes have to be settled. Writers on separate machines change one store at the same time, so the store needs a defined way to settle those changes: through the version control the store sits in ([[20260615100008]]), or through storage that settles it.
