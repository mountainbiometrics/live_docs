## Decision

`renderHome` builds five orientation panels from the inlined export:

1. **Stats** — total docs plus per-type and per-status counts.
2. **Store root** — the largest signpost (transitive `descCount`), highlighted.
3. **Entry points** — all signposts ranked by subtree size (`[[20260619235049]]`).
4. **Hot docs** — top eight by `history.length`.
5. **Orphans** — `belongs_to` roots with no descendants and no signpost role.
6. **Deprecated** — `status: deprecated` docs with resolved `superseded_by` links (broken link if missing).

Every list entry uses the shared resolver (`[[20260619204822]]`) and facet display (`[[20260624202025]]`).
