## Statement

The viewer is a **dumb read-only projection** of the store. It renders the pure-data export and nothing more: it carries no schema judgment, computes no canonical state, and **never performs write operations**. Any logic worth having lives in the **shared code** behind the porcelain ([[20260615185417]]), not in the viewer.

## Rationale

This is the presentation-layer expression of two existing commitments: logic lives once in shared code that every surface calls (skills and viewers are thin consumers), and the porcelain is the sole schema authority and sole mutation path. A viewer that stayed dumb cannot fight the tooling's invariants or pollute the change-trail, because it has no path to write. Keeping intelligence in one place — the shared code — is what lets the viewer be swapped, regenerated, or reimplemented freely without risking the store.
