## Decision

Explicit term references use **double curly braces**, separate from doc-id wiki-links (`[[` + 14-digit id + `]]`).

### Authoring forms

- Ubiquitous: `{{Cascade}}`
- Contextual: `{{(Lexicon) Term}}` — context in parentheses, Title Case
- Path form: `{{lexicon/term}}` — lowercase slug path
- Display alias: `{{hard-edge|Hard Edges}}`
- **Inflection suffix outside the braces:** `{{Hard Edge}}s` → links the singular term, displays “Hard Edges”; `{{Box}}es` → “Boxes”

### Soft semantics

- **Broken links are allowed and useful** — linking a term that does not yet exist signals it *should* be documented.
- If a term is replaced under a new identity (delete + recreate), old references stay broken or point at the old identity; they are **not** rewritten to the new term.

### Display

Prose/display form is Title Case; with context, `(Context) Term`. Machine/path form remains `context/term` (kebab-case lowercase).
