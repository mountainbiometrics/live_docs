## Decision

Explicit term references in doc bodies are **soft wiki-links** in the `[[…]]` family, distinguishable from bare doc-id links (`[[` + 14-digit id + `]]`).

### Authoring forms (all equivalent for a given term)

- Ubiquitous display: `[[Cascade]]`
- Contextual display: `[[(Graph) Cascade]]` — context in parentheses, Title Case
- Path form: `[[graph/cascade]]` — lowercase slug path

Anything in `[[…]]` that is **not** a 14-digit doc id is treated as a term reference candidate.

### Soft semantics

- **Broken links are allowed and useful** — linking a term that does not yet exist signals it *should* be documented.
- If a term is replaced under a new identity (delete + recreate), old references stay broken or point at the old identity; they are **not** rewritten to the new term.

### Display

Prose/display form is Title Case; with context, `(Context) Term`. Machine/path form remains `context/term` (kebab-case lowercase).
