## Statement

**Silence is not ratification.** When an agent proposes a claim and the user does not contradict it, that is not confirmation. The claim must remain `level: incidental` unless the user explicitly states or confirms it.

## Why

Agents currently fail at tracking what came directly from the user with high priority. The observed failure mode: an agent articulates a suggestion, the user stays silent or merely continues, and a later agent treats the store as proof that "we have to do it this way because you said so." That fabricates authority.

`level` is claim settledness, not a synonym of `type: requirement` and not a signal that a provenance edge exists ([[20260615100014]]). A working-session digest as provenance does not elevate every agent articulation in that session. Skills must operationalize this rule — KB recording alone does not reach external agents ([[20260624225658]]); skills are being refined in parallel to do so.

## Out of scope

A full provenance-tier enum (user-stated / user-confirmed / agent-inferred) may be desirable later. Consumer stores may put attribution in free-form bodies. Neither is required here; the durable claim is silence ≠ ratification and incidental for unconfirmed agent articulations.
