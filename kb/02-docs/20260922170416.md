The repo's code becomes one installable distribution: the shared library and the MCP endpoint install together, and the endpoint's third-party dependencies sit behind an optional extra rather than a separate package. The endpoint no longer needs a checkout of the repository to run — a deployment depends on its code as a declared package dependency, chosen over a checkout the deployment manages or a submodule pinning a commit, because the code is a hard dependency and the store it serves already tracks a remote's tip rather than a pin. The pre-existing reason for keeping the endpoint's dependencies off ldoc is unchanged. A deployment shape also exists — a front that authenticates and proxies to the endpoint on loopback — consistent with, not additive to, the endpoint's existing design that its token check is network hygiene, not an auth system.
