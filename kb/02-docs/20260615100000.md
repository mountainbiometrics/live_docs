## Statement

live_docs is just markdown files in a normal filesystem. Git, Obsidian, and similar tools are optional conveniences; functionality lives in thin skills and scripts layered on top, never in a mandatory tool.

## Rationale

Mandatory tooling creates adoption friction and brittle dependencies. Any practitioner—human or LLM—must be able to read, write, and navigate the system with nothing but a text editor and a shell. The moment a workflow breaks without a specific tool, the system has failed this principle.
