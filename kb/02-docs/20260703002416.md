## Decision

A consumer references a shared store by a **name**, not only by a path. The store declares its own **`name`** in its committed `.live_docs.toml`; a consumer marker points at it with `store = "<name>"`. The name is the portable, committable identifier; the store's location is resolved per machine through the per-user registry, and that location may be a local root or the url of a host that serves the store ([[20260916171913]]).

A store must declare a `name` to be referenced this way — a purely self-hosted store with no external consumers needs none. When a name cannot be resolved, `ldoc` fails loud with an actionable message, distinguishing a name that was never registered from one that is registered but whose location cannot be reached.

## Rationale

The `store` key already delegates a consumer to an external store; taking a *name* instead of a hard path is what makes that delegation portable across machines and teammates. The store owns its own name because the consumer's reference is committed and must mean the same thing for everyone, and the name/location split follows the portable-identifier principle.
