How docs connect: the typed-edge vocabulary, what each edge means behaviorally, the graph rules, cascade semantics, and the topology-scope relationship.

The entry point is `[[20260617144634]]` (Edge Type Vocabulary), which names the four edge types — belongs_to, requires, relates, provenance — and what each is for. `[[20260617144542]]` (Name Edge Types After Behavior) gives the rationale: edges are named for behavioral semantics, not conceptual category. The method is to enumerate functional dimensions, fill a behavioral matrix, and collapse identical rows — the resulting names reflect what each edge *does* rather than what it *feels like*. `[[20260617144637]]` (Rename References to Provenance) closes a concrete vocabulary question: provenance and relates are distinct and not collapsible, and the old `references` field name is superseded. `[[20260617144556]]` (Graph Cycles Are Legal) governs structural constraints: acyclicity is a per-edge-type property, not a graph-level rule — cycles are legal where they make sense.

Three earlier decisions set the model's foundations. `[[20260615100007]]` (Unidirectional Deps) established that only the forward direction is stored in frontmatter; the reverse is a generated, rebuildable artifact — bidirectional storage risks the two directions disagreeing, a meta-drift problem inside the drift-tracking system itself. `[[20260615100009]]` (Doc-to-Doc Edges) keeps every edge between docs; a doc's relationship to the implementation is recorded on the doc as realization anchors, which cascade never walks. `[[20260615100012]]` (Cascade Verdicts) defines what cascade checks emit: one of four verdicts per dependent — inconsequential, cascade, incompatible, or context-request — every verdict recorded regardless of type.

The two newest members close the loop between the edge model and the scope facet system. `[[20260619235018]]` (Scope Is Topological) establishes that scope is a topology-derived facet, not a hand-stamped tag: set on an ancestor, it fans down the full `belongs_to` subtree. `[[20260619235034]]` (Belongs-to vs Requires) sharpens the distinction: `belongs_to` confers scope and lineage inheritance; `requires` is a logical dependency that does not. That distinction is now load-bearing because effective scope is computed over `belongs_to` only, never `requires`.
