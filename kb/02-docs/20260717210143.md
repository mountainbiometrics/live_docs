## Statement

Docs with `type: reference` or `status: reference` are kept so current docs can cite frozen material. They are not living documentation. Their prominence across store surfaces is equivalent to a footnote backlink: available when followed from a citation, never presented as peer entry points to the system's current model.

## Rationale

The store's job is to show what the system *is*. Reference material supports that by preserving provenance and source context, but flooding orientation surfaces with those snapshots teaches readers — especially agents — to treat archive noise as the model. Footnote-grade prominence preserves reachability without stealing attention.
