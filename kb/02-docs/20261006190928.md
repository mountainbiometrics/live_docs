## Goal

When the doc metadata model changes, every existing store moves to the new structure through a normalized, repeatable process: a script, an agentic procedure, or both. Each store's move is the same move, run the same way.

## Why

A change to the doc structure reaches every store that uses live_docs, not only the one where it was designed.
