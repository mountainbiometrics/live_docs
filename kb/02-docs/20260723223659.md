## Statement

Durable names — especially `label` and `title` — should prefer the **session's or user's actual vocabulary** over agent-coined terms. If the source already named the thing, use those words. If the user rejected a term and supplied another, use theirs.

## Why

Agent coinages drift from how the human thinks about the system and make later search and conversation mismatch the store. live_docs is a lens into why; the handles should stay in the vocabulary that carried the why. This does not replace the three-descriptor rules for label/title/summary shape ([[20260615230659]]); it constrains *which words* fill those fields. Skills must state and apply this inline — KB alone does not reach external agents ([[20260624225658]]).
