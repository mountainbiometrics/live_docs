The viewer is an optional, read-only reader layered on top of the live_docs store. The store stays presentation-agnostic; everything here is additive client-side rendering in `scripts/viewer/template.html`.

**Design spine** (load-bearing, stay at this level): `[[20260619204742]]` (pure-data export — frontmatter JSON + raw markdown, no baked HTML), `[[20260619204802]]` (purpose-built reader, not Obsidian), `[[20260619204803]]` (self-contained file:// artifact, uncommitted), `[[20260619204821]]` (dumb projection — render only, never write), `[[20260623191806]]` (porcelain auto-rebuild after mutations).

**Integration surfaces** — each top-level nav page or shared module is its own component:

| Nav / module | Component | Role |
|---|---|---|
| *(shared)* | `[[20260624205459]]` Link Resolver | wiki-link resolution, inlining tiers, type icons |
| Home | `[[20260624205460]]` Dashboard View | structural orientation — stats, signposts, orphans |
| Reader | `[[20260624205461]]` Reader View | hierarchy tree + focus pane |
| Catalog | `[[20260624204545]]` Catalog View | facet table / click-to-filter |
| Reviews | `[[20260624205521]]` Reviews View | read-only review queue |

**Cross-surface conventions** (not tied to one page): `[[20260619204849]]` (three navigation modes — hierarchy/facet/graph), `[[20260623215600]]` (default type-then-label sort), `[[20260624202025]]` (scope breadcrumbs + domain pills), `[[20260624204553]]` (Title Case schema enums), `[[20260619204918]]` (v1 read-only — writes via CLI snippets).

**Context**: `[[20260618214213]]` (navigable store goal), `[[20260618214139]]` (grouping is agentic), `[[20260619235049]]` (structural entry points — lives under Dashboard).
