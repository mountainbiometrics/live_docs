## What this component covers

The Viewer Subsystem is the optional read-only HTML interface to the live_docs store. It is structured into two layers: the **architectural foundation** (what the viewer IS and its core constraints) and the **interface components** (what the viewer shows and how users navigate it).

Start with [[20260626174302]] (Viewer Architecture) for the load-bearing invariants — pure-data export contract, self-contained artifact, purpose-built design, dumb read-only projection, and the porcelain auto-rebuild integration. Those decisions constrain everything else in this subsystem.

## Interface components

Five integration surfaces each own their piece of the viewer:

- **Dashboard** ([[20260624205460]]): the home page — structurally derived stats, signpost entry points, hot docs, orphans, and deprecated lists.
- **Reader** ([[20260624205461]]): hierarchy mode — the belongs_to sidebar tree, focus pane with body, members, connections, history, and embedded neighborhood graph.
- **Catalog** ([[20260624204545]]): facet navigation — a filterable table over every doc's frontmatter, with scope and domain facets and click-to-filter chips.
- **Reviews** ([[20260624205521]]): read-only review queue — collapsed cards, signoff badges, and copy-paste CLI snippets for sign-off.
- **Link Resolver** ([[20260624205459]]): the shared client-side markdown and wiki-link resolver used across all surfaces, with inlining tiers and type icons.

## Presentation decisions

Three cross-cutting UX decisions apply across surfaces: default **doc sort order** (type rank then alpha, [[20260623215600]]), **facet display** (scope as breadcrumb trail, domain as flat pills, [[20260624202025]]), and **enum rendering** (type/status/level in Title Case in display; raw strings for filtering, [[20260624204553]]).

## A note on grouping judgment

[[20260618214139]] records the principle that navigation grouping and summarization are agentic judgments, not mechanical rollups — the viewer renders what the gardening pass has decided, it does not decide group membership itself.
