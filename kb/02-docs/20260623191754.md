After any successful ldoc command that mutates viewer-visible store content (docs/ or reviews/), the porcelain automatically rebuilds build/viewer.html so the read-only HTML reader stays current without a manual ldoc viewer step. Rebuild is silent by default, opt-out via --no-viewer or LIVEDOCS_AUTO_VIEWER=0, and must never cause porcelain commands to fail.
