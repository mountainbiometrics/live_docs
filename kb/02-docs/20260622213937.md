## Context

The live_docs porcelain should support per-user CLI configuration outside any store, following git's precedent.

## Intent

After this work, a user configures identity once in `~/.config/live_docs/config.toml` using a git-compatible `[user]` table (`name`, `email`). `ldoc review sign` defaults to the git author-line format `Name <email>`; `--as` overrides. `ldoc config user.name` / `user.email` reads and writes these values (git config-style). The command works without a located store. `install.sh` bootstraps from `git config --global` when `user.name` is unset — via the git porcelain, not by parsing `~/.gitconfig` directly. The same home config file may also hold store-path fallbacks when no `.live_docs.toml` is found in the CWD tree.
