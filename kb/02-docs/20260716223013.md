## Decision

The lexicon occupies a configurable store box key **`lexicon`**, defaulting to **`kb/lexicon/`** beneath `base`. It is an **unnumbered sibling box** — the same class as `kb/reviews/` and `kb/sessions/` — not a numbered distillation stage (`00` / `01` / `02`).

Term records in that box are **outside the knowledge graph**: they do not participate in cascade or validate-as-docs. The box path resolves through the same discovery rules as other boxes ([[20260618214257]]).

## Rationale

Distillation stages encode capture → raw → atomic doc. Vocabulary ratification is process-adjacent store state, not another distillation tier — the same reason reviews and sessions stay unnumbered ([[20260618214315]]).
