The read-only HTML viewer should surface domain tags as prominently as scope: domain pills appear everywhere scope pills do (headers, tooltips, lists). On the Catalog page, add domain filter dropdowns alongside existing facets and drop the redundant title column (label suffices). Scope display condenses the inherited scope union into a single hierarchical path pill — e.g. live_docs/viewer instead of separate live_docs and viewer pills — reflecting the belongs_to anchor chain.
