## Decision

A lexicon term record's **on-disk** frontmatter fields are (omit empty):

| Field | Role |
|-------|------|
| `term` | Canonical display form (Title Case) |
| `definition` | Definition text |
| `context` | Optional homonym disambiguation; omit when ubiquitous |
| `allowed_aliases` | Optional list of accepted surface forms |
| `restricted_aliases` | Optional list of discouraged surface forms |
| `similar_terms` | Optional soft refs to other terms (not graph edges) |

**There is no `id` frontmatter field.** Identity is the filesystem path (`lexicon/<term>.md` or `lexicon/<context>/<term>.md`). Tooling and the viewer export may **derive** a path id in memory for resolution and stats — that derived id is not an authored schema field.

**There is no `created` field.** Git history is sufficient if anyone needs when a term file appeared or changed.

Term records have **no** `status`, **no** cascade participation, and **no** `history`.
