Top-level **Reader** (`#/<doc-id>` routing). Implements the hierarchy navigation mode from `[[20260619204849]]`.

**Sidebar**: `[[20260623215558]]` — visual nesting, stateful expand/collapse, ancestor reveal on navigation. Reference/archived docs are omitted per `[[20260710235236]]`.

**Focus pane**: doc body via shared resolver; signposts also get `[[20260619204840]]` (orientation guide + derived member list + optional compose-inline-members). Every focused doc shows `[[20260624205515]]` (two-column connections / backlinks) and `[[20260624205516]]` (collapsed history timeline). Doc ids appear as secondary badges (`[[20260710235234]]`).

**Side panel**: single-click wiki-link peeks open here (see `[[20260619204904]]`); the neighborhood graph (`[[20260624205517]]`) is always mounted beside the focus — exploration without burying the body.
