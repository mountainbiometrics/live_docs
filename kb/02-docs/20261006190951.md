## Decision

Every listing and search orders docs by three keys, in place of oldest-first:

1. `status` — living, then deprecated, then reference;
2. `intent` ([[20261006190938]]) — requested, then chosen, then unattributed, then incidental;
3. relevance — the surface's own ordering, such as how well a search term matches.

Ranking reference docs last is the same rule demotion applies to search ([[20260717210152]]).

## Why

Readers meet the most intentional docs first and reference material last ([[20261006190936]]).
