## Decision

The viewer renders a small **Lucide SVG icon immediately before each doc label** wherever type is conveyed visually (tree, links with `{icon:1}`, tooltips, doctitle). Icons are inlined from vendored path data — no CDN — keyed by the `TYPE_ICONS` map in `scripts/viewer/template.html`.

A collapsible **type legend** in the top nav (`renderTypeKey`) lists only types that actually occur in the export, sorted by canonical type rank (`[[20260623215600]]`), with Title Case labels (`[[20260624204553]]`).

## Rationale

Trailing type pills duplicated information already carried by label context and cluttered narrow surfaces. Icons convey type at a glance without extra horizontal space.
