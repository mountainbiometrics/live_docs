## Decision

Navigation has **three orthogonal modes**, each answering a different question:

- **Hierarchy** — `[[20260624205461]]` (Reader View): sidebar tree built from **`belongs_to`**, rooted at descendant-bearing structural components. Answers "where does this sit in the curated structure?" Sidebar UX: `[[20260623215558]]`; default sibling order: `[[20260623215600]]`.
- **Facet** — `[[20260624204545]]` (Catalog View): filterable table over frontmatter. Table layout and click-to-filter: `[[20260624204552]]`.
- **Graph** — `[[20260624205517]]` (Neighborhood Graph): always on in the Reader **side panel**, with edge-aware hops (`[[20260624205518]]`).

**Home** (`[[20260624205460]]`, Dashboard View) orients before these modes — stats, entry points, orphans. **Reviews** (`[[20260624205521]]`) is a separate read-only queue page. Shared link resolution: `[[20260624205459]]`.

## Priority

**Hierarchy and facet are the primary daily drivers.** The graph is ambient exploration beside the focused doc — valuable without requiring a separate page or a toggle under the body.
