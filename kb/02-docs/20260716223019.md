## Capability

`ldoc term` is the porcelain surface over the lexicon sibling box ([[20260716223013]]). Terms are outside the doc graph — these verbs do not participate in cascade or doc validate.

| Verb | What it does |
|------|--------------|
| `term new` | Create a term (`--term`, `--definition`, optional `--context`, alias lists) |
| `term get` / `term show` | Read term fields or a full term view |
| `term ls` / `term find` | List or search terms |
| `term set` | Update definition or alias lists (identity changes refused in place) |
| `term rm` | Delete a term; soft links stay broken |

Identity is the path ([[20260716223014]]). Renaming means delete and recreate under the new path — old soft links are not rewritten ([[20260716223016]]).
