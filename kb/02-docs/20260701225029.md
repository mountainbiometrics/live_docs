## Decision

`session close` **blocks** until every doc that received a **revision-class** change during the session carries at least one **author-supplied** note. Per-command, a missing note only **nags** — a warning, never a block, consistent with review-is-post-hoc; the gate sits at **close**, where a human actually reads the roll-up.

## What discharges the gate

**One** author note per doc suffices — a second body tweak to an already-explained doc rides free. **Auto-filled** notes discharge their *own* change classes (addition, restructure, organizational, deletion never block close) but do **not** stand in for a revision: a body rewrite explained only by an auto "Reparented…" note is exactly the case this gate exists to catch. Gaps are filled with the demoted `ldoc history` verb.
