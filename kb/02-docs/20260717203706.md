## Intent

Reference and archived docs are kept so living docs can cite them — their role is footnote-grade, not peer to living documentation. Navigational prominence across the system (viewer and CLI) should match that: omit or demote them from default orientation surfaces, rank them last in search, and treat them as immutable snapshots (delete and re-snapshot rather than edit).

The viewer already demotes references (tree/graph/catalog defaults). The CLI does not: `ldoc map` and similar orientation surfaces still present floating/unscoped reference docs as if they were the living model. That gap is critical for agents, because CLI orientation is what they explore and learn from — not a nice-to-have cleanup.
