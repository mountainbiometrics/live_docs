## Restatement

`ldoc session close` must not fail when a `type: reference` / `status: reference` doc was created (or otherwise touched) during the session. History materialization at close is a projection onto living docs; reference/archived snapshots refuse history writes, so close must skip those docs (or treat their refusal as success). The review still records the addition from the WAL. This is on the happy path — apply-to-docs Step 1b creates exactly such a reference mid-session.
