## Requirement

A doc may carry implementation details when the people working on it want them recorded. The discipline of capturing the why rather than the what ([[20260625222613]]) governs what a doc claims; it leaves room for pointers into the implementation and notes about how a claim is currently built.

## Why

Pushing harder and harder for "no implementation details" grew out of agents refusing iterative changes to a ratified-looking shape ([[20261006190926]]). Parts of that discipline are important, but there is a silliness in it: if people want to record implementation details, the system should allow that. Pointers into the code are also what an agent follows when it syncs docs and code ([[20261006190925]]).
