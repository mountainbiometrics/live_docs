## Decision

`neighborhood(focus, depth)` BFS-expands across all edge types (forward + reverse). Defaults:

- **Depth 1-hop** — focus + direct neighbors (session default via `graphView.depth`).
- **Depth 2-hop** — user opt-in via radio control.
- **NODE_CAP 40** — expansion stops with a visible cap warning; 1-hop neighbors are always kept.

Rendering: hand-rolled Verlet-ish force loop to inline SVG. Each edge type has a color, toggle, distance, and strength slider (`graphPrefs`). Clicking a node sets `location.hash` to refocus Reader on that doc.
