## Requirement

Before writing any changes, the `apply-to-docs` skill must evaluate the total blast radius of the request's impact on the store. If the impact exceeds defined thresholds, the skill must halt and surface a structured warning to the user before proceeding.

## Thresholds (any one triggers the gate)

- `supersede-full` count ≥ 2
- `supersede-partial` + `supersede-full` combined ≥ 4
- Any `conflict-unresolved` docs present

## Warning format

The warning must list: total affected doc count, per-verdict counts, a doc-by-doc list with ids and titles, and a conflict description for any `conflict-unresolved` items. The user must explicitly confirm (yes / no / resolve conflicts first) before writes proceed.

## Rationale

A request that overrides many prior decisions may represent a paradigm shift or a mistake. Silently applying many supersessions destroys the accumulated knowledge without giving the user a chance to reconsider or catch errors.
