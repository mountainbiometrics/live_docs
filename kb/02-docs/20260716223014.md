## Decision

Lexicon entry identity **is the term slug** (plus optional context for homonyms). There are **no opaque timestamp IDs** for terms.

### Paths

- Ubiquitous term → `lexicon/<term>.md`
- Contextual term → `lexicon/<context>/<term>.md` (`/` matches directory layout)
- Multi-word segments use **kebab-case lowercase** slugs (e.g. `allowed-aliases`)

### Rename semantics

A "rename" is a **different term**: delete the old record and create the new one. Existing references are **not** rewritten or backfilled — that is how language works, not how foreign-key links work. Old soft links stay broken or point at the old identity.

### Homonyms

Where the same string means different things, disambiguate with **`context`**. Terms are ubiquitous by default — `context` only when needed.
