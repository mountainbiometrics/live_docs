## Principle

Before committing any new knowledge to the store, the agent must survey existing docs for compatible, conflicting, or superseded claims. The search-and-assess phase is not optional scaffolding — it is the mechanism that prevents contradictory truths from accumulating.

## Corollary

Creating a new doc without first searching for an existing doc that makes the same or opposing claim is a violation of this principle. The correct action is always: search first, then decide whether to create, revise, or link.

## Scope

Applies to all store-mutating skills: `ingest-reference`, `apply-to-docs`, `revise-doc`, and any future skill that creates or modifies docs.
