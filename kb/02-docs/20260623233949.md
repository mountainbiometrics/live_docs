## Context

A doc's home in the hierarchy can be set when the doc is created or left for a later gardening pass. Leaving *all* placement to gardening means every newly created doc is born homeless and waits for a separate pass to find it a parent — even though, at creation time, the writer already holds the concepts and edges that point at a reasonable home.

## Decision

The ingest/apply writer **originates** a doc's `belongs_to` placement **at birth**: when it creates a doc it picks the best visible signpost from the concepts and edges already in hand and gives the doc a *semi-adequate* parent immediately, applying the shared placement definition. Gardening's role is to **refine** placements later, with full-store context — second-guessing and improving birth placements, re-homing docs as the tree evolves — **not to originate every placement**.

The division of labor is: **ingest originates** (cheap, local, good-enough), **gardening refines** (global, authoritative). Both read the one shared placement definition, so an originated placement and a refined placement are judged against the same standard.

## Consequences

- A new doc enters the store already in the tree under a plausible parent, rather than as an orphan awaiting cleanup — lowering the future gardening load.
- The writer need not survey the whole store to place a doc; "best visible signpost from what is already in hand" is sufficient, because gardening will refine it.
- This is justified **on its own merits** — lower future gardening load, better birth placement, and a single shared definition of good placement
