## Decision

Store name→location bindings live in the **per-user config** — `~/.config/live_docs/config.toml` — as `[store.<name>]` tables carrying the local `root`. This is a third role for the home config, alongside its existing per-user identity table and store-path fallbacks. The binding is per-machine because only the location varies per checkout; the name is shared.

## Rationale

The location of a shared store differs on every machine, so it cannot be committed — it belongs in the one place that is already per-user and uncommitted. Reusing the home config keeps all per-user, per-machine settings in a single known file instead of inventing a new registry format or location.
