## Decision

Store name→location bindings live in the **per-user config** — `~/.config/live_docs/config.toml` — as `[store.<name>]` tables. A binding carries the store's **location**: either the local `root` where the store is checked out, or the `url` of a host that serves it ([[20260916171913]]). This is a third role for the home config, alongside its existing per-user identity table and store-path fallbacks. The binding is per-machine because only the location varies; the name is shared.

## Rationale

The location of a shared store differs on every machine — and for a machine with no checkout it is not a path at all — so it cannot be committed. It belongs in the one place that is already per-user and uncommitted. Reusing the home config keeps all per-user, per-machine settings in a single known file instead of inventing a new registry format or location.
