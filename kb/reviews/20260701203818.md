## Additions
- [[20260701203425]]
- [[20260701203656]]
  An editing session is the concrete, id-identified unit of editing work — the actualized form of the formerly-virtual 'episode.' One owner opens a session, every change made during it is stamped with the session id, and closing the session mints exactly one review summary over those changes.
- [[20260701203750]]
  The open session's id lives in the shell environment (LDOC_SESSION), so every independent ldoc invocation — and any subagent that inherits the environment — attributes its changes to the same session, without threading a session id through command arguments. Chosen over per-command passing or a persisted state file.
