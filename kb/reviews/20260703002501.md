## Summary

Captured the named-stores design born-living: principle (portable identifier / local location), requirement (committable store reference), constraint (no silent rebinding), and decisions (named stores, per-user registry, fail-loud registration, --alias), wired to each other and to Store Delegation; refreshed the Store Layout signpost.

## Additions
- [[20260703002412]]
  Design-session digest: a consumer references a shared store by a name the store declares; a per-user registry maps name to local path; registration is fail-loud; --alias is the collision escape hatch. Commit the name, resolve the location per machine.
- [[20260703002413]]
  When a reference must work across machines, commit only the stable identifier and resolve the machine-specific location separately, per user. Prior art: git remotes, AWS profiles, kube contexts, SSH host aliases.
- [[20260703002415]]
  A conflicting store-name registration fails loudly instead of overwriting, so duplicate clones or copied configs cannot silently hijack a name.
