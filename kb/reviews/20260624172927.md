- [[20260624172648]]
  Single responsibility requires that exactly one doc owns a claim — not just that a doc has one topic. If multiple docs each partially address the same claim, none is the real owner. Collapse (merge or fold) is the repair for diffuse ownership, as decompose is the repair for overloaded scope.
- [[20260624172702]]
  Placement correctness (individual doc level) and tree navigability (branch level) are independent axes. Every child of an overgrown branch can be correctly placed and yet the branch itself is still a navigability failure. Both axes require independent maintenance.
- [[20260624172719]]
  Multi-agent doc pipelines produce intermittent, non-deterministic inconsistency in naming and structure — a structural property, not an occasional bug. Sampling-based spot-checking is the correct QA response: neither exhaustive full-scan validation (which catches schema errors) nor manual review.
- [[20260624172737]]
  Sub-skills handle shared procedure (same steps every caller executes identically); prose includes handle shared text (a definition or policy that each caller reads and applies with its own judgment). Using a sub-skill for a definition over-engineers the skill graph and obscures that the consumer is just reading a policy.
