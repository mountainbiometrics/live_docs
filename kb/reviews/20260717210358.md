## Summary

Store Interfaces nest CLI+viewer; footnote-grade references demoted store-wide (validate opt-in); reference snapshots immutable

## Additions
- [[20260717210142]]
  The interface layer between actors and the store: porcelain/CLI and the HTML viewer nest here. Cross-cutting presentation rules that bind every surface live under this signpost, not under a single implementation.
- [[20260717210143]]
  Reference and archived docs exist for citation, not as peer claims. Their navigational prominence is that of a footnote backlink: reachable when something cites them, never competing with current documentation for attention.
- [[20260717210152]]
  Orientation, listing, and default validate omit docs with type:reference or status:reference; find ranks them last. They stay resolvable and appear in per-doc connection lists. Opt-in flags expose them because archive integrity is not a requirement for the current model.
- [[20260717210153]]
  Porcelain refuses substantive mutations to docs with type:reference or status:reference. Wrong snapshots are deleted and re-created, not edited in place — keeping the live_docs vs frozen-material distinction sharp.
